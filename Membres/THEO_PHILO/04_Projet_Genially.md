# 🧠 Projet Genially – Carte mentale interactive

## Objectif
Créer une carte mentale interactive pour chaque chapitre, avec un système de "flashcards" (retournement).

## Structure
- **Rouge** : Les grandes questions du chapitre.
- **Vert** : Les méthodes (comment on répond à la question).
- **Bleu** : Les zones de réponse (laissées vides pour que l'élève réfléchisse).
- **Bouton "Correction"** : Un bouton sur le côté qui permet de "tourner" la carte pour révéler les réponses.

## Ce que je peux faire
- Générer la structure textuelle (questions, méthodes, réponses).
- Écrire les prompts pour l'IA de Genially.
- Décrire les interactions souhaitées.

## Ce que je ne peux pas faire
- Cliquer dans Genially à ta place.
- Générer l'animation directement.
