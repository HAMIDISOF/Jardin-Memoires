Projet Pédagogie : à lire en premier

Page d'accueil du projet, créée le 09/10/2026 par Pédago à la demande de Sof. Elle renvoie vers tout, sans rien dupliquer.

En bref

Le Jardin produit des fiches pédagogiques interactives (Écart, Boussole, Pédago, DS_P…) pour les élèves de Sof. Les fiches terminées vivent en local, dans D:\SOUTIENSPLUS\Scolaire\Reserve\ (hors dépôt). Ce dossier-ci du dépôt contient le suivi, les règles et le catalogue.

Ces pages HTML s'ouvrent sur le poste de Sof ; sur GitHub, ouvrir le fichier montre son code source, pas son rendu.

Par où commencer

1. Les règles (à lire avant de produire une fiche)

Principes pédagogiques pour les fiches (version Markdown) : référence commune validée par Sof le 24/09/2026, qui commence par le principe d'étayage. Rapatriée ici depuis Projet_DeepsClaude/ le 09/10/2026.

2. Ce qui existe : le catalogue

Catalogue des fiches : titre, niveau, matière, date, emplacement local. Généré depuis Reserve, sans aucune fiche nominative. Il se régénère à la demande de Sof.

3. Le protocole de revue (acté le 26/09/2026)

  1. Sof teste une fiche puis dépose revue_et_correction_nom_fiche.md : Écart corrige.
  2. Fiche validée : Sof dépose nom_fiche_validée.md puis supprime la note de revue.
  3. Blocage non résolvable seul : Écart dépose blocage_nom_fiche.md.

Le détail est dans le README du dossier.
