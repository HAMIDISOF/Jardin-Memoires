# Projet Pédagogie — Fiches interactives

Dossier de suivi et de partage des fiches pédagogiques produites par le Jardin Coopératif (Écart + Boussole, avec Pédago et DS_P).

**Point d'entrée : `LIRE_EN_PREMIER.html`.** Catalogue de ce qui existe : `Catalogue_fiches.html`.

## Où est quoi

- `LIRE_EN_PREMIER.html` — page d'accueil avec les liens vers tout (créée le 09/10/2026, Pédago)
- `Catalogue_fiches.html` — fiches existantes (titre, niveau, matière, date, emplacement local)
- `Regles/Principes_pedagogiques_fiches.md` / `.html` — référence commune validée le 24/09/2026 (rapatriée de `Projet_DeepsClaude/` le 09/10/2026)
- Notes et outils de ce dossier : `2nde_Ensembles nombres.md`, `2nde_ensembles_nombres_pilote.html`, `Animation engrenages.md`, `Fiche_5°_grammaire_maths.md`, `Script narration irrationnels.md`, `outil_correction_dictee.md`
- Les autres documents du duo Pédago × DS_P restent dans `../Projet_DeepsClaude/` (protocole du duo, note de synchro, échanges, journal des délégations)

## Où vivent les fiches terminées

En **local**, hors dépôt : `D:\SOUTIENSPLUS\Scolaire\Reserve\<niveau>\<matière>\` (une fiche = un seul emplacement). Le dépôt ne contient que le suivi, les règles et le catalogue. Depuis le 01/10/2026, les fiches produites par Écart et téléchargées par Sof sont triées et rangées dans `Reserve`.

## Protocole de revue (acté le 26/09/2026)

- Sof dépose `revue_et_correction_nom_fiche.md` après avoir testé une fiche → Écart corrige
- Fiche validée : Sof dépose `nom_fiche_validée.md` puis supprime la note de revue
- Blocage non résolvable seul : Écart dépose `blocage_nom_fiche.md`
